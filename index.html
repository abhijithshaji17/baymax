PRIVACY, IN PLAIN LANGUAGE

What stays where?

  • Chat: held in this browser tab’s memory. The server does not write message content to logs.
  • AI mode: if configured, messages are sent to the server and OpenAI to generate a reply. Don’t share anything you wouldn’t want processed for that request.
  • Demo mode: no message is sent to an AI provider; the app shows a fixed sample reply.
  • Notes: stored in this browser profile only after you check the consent box and save. Clear them in My notes.

This demo is not a medical device, clinician, or emergency service. For immediate danger, contact local emergency services or a nearby trusted person.
